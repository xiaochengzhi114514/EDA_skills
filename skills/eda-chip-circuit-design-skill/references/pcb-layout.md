# PCB 布局与走线审查

本参考用于 `design`、`audit` 和 `capture` 模式。当任务包含电源、模拟、数字接口、阻抗、铺铜、过孔或 PCB 版图要求时读取；不要把示意图上的视觉连通性当作 ERC/DRC 或 SI/PI 验证。

## 1. 先按电流和频率分区

把网络分为四类，并在布局图中标出：

| 类别 | 典型网络 | 处理原则 |
|---|---|---|
| 高 di/dt 功率回路 | Buck 的 VIN–U1–PGND–续流二极管、PH–L | 最小环路面积、最短连接、顶层优先；禁止敏感线穿越 |
| 大电流低频回路 | VIN、VOUT、PGND、连接器 | 按电流和温升定线宽或铺铜，检查过孔电流和压降 |
| 敏感模拟 | FB/VSENSE、COMP、SS、基准、采样 | 远离 PH 和电感，短线、安静地回 U1 地，必要时 Kelvin 取样 |
| 高速/时钟/差分 | USB、LVDS、SerDes、晶振 | 只有接口规范要求时才做受控阻抗；按叠层和厂商阻抗表设计 |

先锁定器件位置、层叠、铜厚、线宽线距、过孔和阻抗目标，再画线。没有叠层和制造商能力时，不声称某个线宽“就是 50 Ω”。

## 2. TPS54331 非同步 Buck 的固定检查项

依据 TI TPS54331 SLVS839H 第 25 页布局指南：

1. `CIN` 正端、U1 `VIN`、U1 `GND`、续流二极管阳极形成的输入高 di/dt 回路要闭合且最小；CIN 紧靠 U1 VIN/GND。
2. U1 `PH` 到二极管阴极和电感输入的铜箔只保留必要面积；不要在其下方或旁边走 FB、COMP、SS、时钟或连接器信号。
3. 二极管阳极、输入电容负端、输出电容负端和 U1 GND 接到同一低阻抗功率地；U1 GND 直接落到连续地平面。
4. 电感后端为 `VOUT`。RFB1 从输出电容正端或负载采样点 Kelvin 取样；FB 节点到 U1 VSENSE 短且远离 PH。
5. RCOMP/CZ/CP 和 CSS 靠近 U1；补偿元件回到 U1 GND 的路径不要与二极管脉冲电流共用细长走线。
6. D 封装没有 PowerPAD；使用 U1 GND 引脚附近的大面积顶层铜和多颗接地/散热过孔连接内层或底层地平面。过孔数量、孔径和环宽必须按 PCB 厂商能力确认。

## 3. 线宽、铺铜和过孔

- 先按最大直流电流、允许压降、铜厚和允许温升计算，再取标准线宽；线宽不能只按电气连通性决定。
- 对 3 A 电源，在 1 oz 外层铜、约 10 °C 温升的 IPC-2221 初估中，裸走线宽度约 1.4 mm 量级；首版建议 VIN/VOUT/PGND 使用至少 1.5–2.0 mm 或直接铺铜，并在样板上测温升。该估算不适用于脉冲 PH 或内层细线。
- 大电流路径尽量不通过单颗小过孔；需要换层时并联过孔，过孔电流和电感由厂商工艺、孔径、铜厚和温升决定。
- 地平面优先保持连续。输入/输出电容回流、二极管阳极和 U1 GND 用短、宽连接接入地平面；不要用细长“地线”替代平面。
- 过孔围栏适合地平面和屏蔽边界，但不能把 PH 围成大电容；PH 区域只保留必要铜皮并远离地过孔密集区。

## 4. 阻抗规则

- TPS54331 的 VIN、VOUT、PGND 和 PH 电源连接通常不需要 50 Ω 受控阻抗；重点是环路面积、寄生电感、压降、EMI 和热。
- 若芯片外围存在数字接口，目标阻抗必须由接口规范或芯片手册给出。例如常见 USB 2.0 差分对约 90 Ω differential，LVDS 常见约 100 Ω differential；这些数值不能替代具体器件规范。
- 单端阻抗通常由板叠层、参考平面、介质厚度、铜厚、线宽和阻焊共同决定。设计规则应来自 PCB 厂商阻抗计算器/场求解器，并在下单前让厂商确认阻抗 coupon。
- 差分对需要同时约束差分阻抗、线宽、线距、长度匹配、参考平面连续性、过孔结构和回流路径。不要只复制“90 Ω”而忽略叠层。
- PH 节点不要为了“阻抗匹配”拉成长 50 Ω 线；应缩短并减小面积。

## 5. 版图审查清单

| 等级 | 检查项 | 通过条件 |
|---|---|---|
| P0 | VIN/CIN/U1/D1 输入回路 | 连接最短，CIN 紧靠 VIN/GND，未被信号线穿过 |
| P0 | PH 铜箔 | 仅连接 U1 PH、D1 阴极、L 输入；面积小；无 FB/COMP/SS 平行走线 |
| P0 | 地回路 | U1 GND、D1 阳极、CIN/COUT 负端进入连续地平面 |
| P1 | 电源线线宽/过孔 | 按 I、铜厚、温升、压降和过孔额定值复算 |
| P1 | VSENSE/FB | 从安静 VOUT 点 Kelvin 取样，远离 PH/L1，FB 节点短 |
| P1 | 热路径 | U1 GND 顶层铜、内/底层地和过孔满足热设计；测量结温 |
| P1 | 补偿/软启动 | 元件靠近 U1，地回路短，无开关节点耦合 |
| P2 | 阻抗和差分 | 仅对真正的高速接口执行叠层阻抗和长度匹配 |
| P2 | EMI | 预留近场探头、滤波器、阻尼/磁珠调整位置，按实测迭代 |

## 6. 输出格式

PCB 相关交付应至少包含：

- 器件相对位置和关键回路示意图；
- 功率、敏感模拟、高速/差分网络清单；
- 线宽、铜厚、过孔和地平面假设；
- 阻抗目标的来源和“待叠层确认”标记；
- P0/P1/P2 版图审查结果；
- 未完成的 SI/PI、热、EMI、DRC 和实测项目。

无 PCB 叠层、铜厚、工艺能力和接口规范时，给出“起始建议 + 需要制造商确认”的组合，不给出虚假的精确阻抗或过孔载流量。
