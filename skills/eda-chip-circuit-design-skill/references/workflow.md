# 资料和决策工作流

## 1. 识别器件

从用户输入抽取完整料号、制造商、版本、封装、温度等级。先查看厂商网页的订货信息和 datasheet 首页/器件比较表，再查看封装引脚图。仅有模糊型号（如“TPS62130 系列”）时，给出可能子型号差异；只有丝印时，提供候选和查证方法，不能确定引脚。

## 2. 资料检索

每次设计都应优先取制造商当前资料；不要把本 skill 内的示例参数当成最新数据。建议检索路径：制造商产品页 → datasheet PDF → application section → reference design/EVM 原理图+BOM → errata → 应用笔记。若用户给出旧版 PDF，记录版本，并检查是否有新版改变引脚、电气条件或推荐外围。

PDF 文本提取可能破坏公式、图形、引脚图和表格。公式或连接关系有歧义时，看原页图像；使用页码时区分 PDF 页号和印刷页号。

资料引用格式：`制造商, 文档标题, 文档号/版本, 发布或修订日期, §章节/表/图, 页码, URL, 访问日期`。若厂商没有清晰修订日期，标注“未见修订日期”。

### 资料级别

| 级别 | 可以支持的结论 |
|---|---|
| A 原厂 datasheet/errata | 引脚、限制、推荐工作条件、必需连接 |
| B 原厂 EVM/参考设计/应用笔记 | 原厂验证过的应用值和布局，适用条件需要照抄 |
| C 分销商资料/第三方板卡 | 库存、替代料、辅助交叉核对 |
| D 经验公式/一般知识 | 初步估算、发现量级错误，不能证明该 IC 的稳定性 |

## 3. 缺失输入的处理

只问会影响拓扑或关键元件的最少问题。可以在输出中采用明确假设继续做初步方案，但假设与最终确定值必须隔离。以下情况不得把电路称为“确定设计”：

- 完整料号或封装未知；
- 输入最高电压/输出最大电流未知，无法选耐压或限流；
- 参考电压、推荐 L/C、补偿条件、绝对最大额定值没有可靠来源；
- 芯片是否适合目标电压/电流/工作温度尚未核对。

提出问题的顺序：料号/封装 → Vin 范围 → Vout/Iout → 负载瞬态/纹波 → 温度/布局/采购偏好。能从用户已有资料推断的，不重复询问。

## 4. 置信度

- **高**：完整料号和封装已核对；数据手册/参考电路匹配目标条件；数值、额定值、稳定性、热和连接均已审查。高置信度仍不等于实测通过。
- **中**：存在已标明的次要假设，元件推荐或极限工况还需厂家工具/实验确认。
- **低**：来源、型号、封装或关键指标不全；只提供条件性建议，不提供“直接投板”结论。

## 5. 样例证据核对（只作流程演示，设计时重新查询）

TI 的 TPS62130/TPS62130A 系列 datasheet `SLVSAG7F`，修订日期 November 2021，在表 6-1 给出 16-pin VQFN 的引脚功能；§9.2 图 9-1 和表 9-1 给出典型 12 V→3.3 V、3 A 参考应用；§9.2.2.2 表 9-2 给出已验证的 L/C 组合，§9.2.2.2.1 解释电感峰值电流和饱和额定值。来源：<https://www.ti.com/lit/ds/symlink/tps62130a.pdf>。本例说明为什么不能只用 `L=(Vin−Vout)D/(fsΔI)` 随意挑一个电感和电容。

## 6. 输出前反查

对每一项具体元件值反查来源和计算。对每一条连接反查引脚表和参考图。对每一个额定值反查最坏工况。找不到依据的数字改为“估算/待确认”；不能用专业语气掩盖证据缺口。
